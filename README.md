# The Last Dream

*The Last Dream is a dark fantasy storytelling website built with HTML, CSS and JavaScript. It takes you through a mysterious world where dreams, memories and choices shape the story.*

## How to Run

1. Extract the downloaded ZIP file.
2. Open the `The-Last-Dream` folder in VS Code.
3. Open `index.html` using Live Server, or open it directly in your browser.

## What’s Inside

- An original fantasy story that follows Mira as she searches for her missing brother, Eli.
- Animated stars, moonlight, misty forests, magical doors and a mysterious sleeping city.
- Smooth animations that bring each part of the story to life as you scroll.
- Three different story paths, each leading to a different ending.
- Interactive memories, hidden messages and conversations with mysterious characters.
- A chapter menu and reading progress indicator to help you explore the story.
- A responsive layout that works on both desktop and mobile.
- Support for reduced-motion settings for a more comfortable browsing experience.

## A Few Things to Know

The website is made with plain HTML, CSS and JavaScript, so you don't need to install any extra frameworks.

The fantasy scenes are created using CSS and canvas animations, rather than external stock images. The fonts may need an internet connection to load.

Your choices affect the story during your visit, but they aren't saved to an online account or sent to a server.

To make the experience more atmospheric, you can pause the animations using the motion control in the header.

## Extra Story Chapters

The expanded version also includes two new scenes: *The House of Echoes*, where Mira discovers a memory connected to Eli, and *The Bridge Between*, where she begins to understand what it means to move forward.

The idea is to make the website feel less like a regular webpage and more like a story you can explore at your own pace.
